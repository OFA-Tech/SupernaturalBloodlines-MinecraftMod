# Plan 16: hub and HUD UI overhaul

Branch per phase from main, one PR each. The approved design is the 34 PNG exports in `docs/superpowers/design/plan16/` (8 pages x 3 themes `grimoire-*`, `bloodmoon-*`, `tensura-*`; 7 `state-*`; 3 `hud-*`). Same rules as plans 13 to 15: TDD where logic exists, server authority, Dist guards, the 10-run matrix with `--no-daemon` to files, one report per phase in `.superpowers/sdd/16-ui/`.

## Owner rules (do not drift)

1. **Add, never replace.** Every page and feature we have stays (Path, Skills with its Faction and Loadout tabs, Quests, Rites, Bloodline, Pack, the launchers, the Tensura menu tab, the three themes, the config theme switch).
2. **Each theme has its own architecture**, same pages and data:
   - **Grimoire**: an open book (leather cover with a gold line, two parchment pages, spine shading, stacked page edges, page numbers). Pages are index tabs out of the right edge (Loadout included); launchers are wax seals on cords below; a brass clasp switches the theme. SP and EP are red-ink margin notes; the main action is a wax-seal stamp, secondary actions are underlined red links; drop caps, dotted leaders, footnotes; the centrepiece is an ink sigil.
   - **Blood Moon**: cinematic. The moon is the emblem and the ladder rungs are gems around it. A round icon rail on the left (a label flag on the active one), launchers on a right rail, SP/EP and a moon theme button top right, the main action in a floating bottom detail bar.
   - **Tensura**: a status window: title bar "Status . X", a stats line, a "Theme" button; a left list of pages plus an "Other mods" group; the ladder is a row of hexes; a **right info pane** holds the selection, tasks and buttons; no bottom bar.
3. **Shared ideas**: a live 3D player model (vanilla `InventoryScreen.renderEntityInInventoryFollowsMouse`, drag to turn) inside the emblem; a tick progress ring; radial skill trees with rank pips and tabs per mod; source tags SB / VMP / WW / ENC / TEN; the pack portrait ring (Alphas red, Betas gold, Packmates blue, Brothers brown, subordinates small and faint at 1/2; ready for plans 14 and 15); the bloodline family tree with player heads and gene vials; a Guide page with species chapters; a lunar calendar; the states (Ghoul, two ladders, no Tensura, empty, confirm, tooltips, focus ring, keys Tab / Enter / 1-8 / arrows / Esc / Home).
4. **Fit**: GUI scale 4 on 1080p is 480 x 270 GUI px. Panels collapse first, text is 8 GUI px or more, contrast is 4.5:1 or more by the existing contrast test.
5. **The theme switch is in the hub** and in the config.
6. **HUD**: plain Caps Lock (not Alt+Caps) switches Tensura / Supernatural mode by default, still rebindable; theme-shaped slots (Grimoire inked tiles with wax key badges, Blood Moon round, Tensura hex); real icons, a cooldown pie with seconds, an active glow, a blood ring on Bite; a mode pill, Alt tooltips, a full-moon warning, compact fade.
7. **Icons**: Minecraft's font has no emoji. Our own 16 x 16 pixel sprites, generated by a script into one atlas texture, for every icon the designs use.

## 16b scope (as built)

Not in 16b, moved to the phases that own their data: drop caps, leaders and footnote marks as a text style, the radial Skills page, the Bloodline family tree and gene vials, the pack ring (16e, or when plans 14 and 15 land the data).

## 16a tasks

1. Pure kit with tests: `TickRing`, `Radial`, `Shapes`, `PackRing` / `PackRole`, `SourceTag`, `FocusOrder` (zones NAV, STAGE, PANEL, ACTIONS and number keys), `ConfirmModel`, `ModelDrag`, `Detail`, `Icons` (names equal the atlas list), `Contrast.bestText`.
2. The atlas: `tools/gen_icons.py` writes `textures/gui/icons.png` (16 x 4 cells of 16 px, white on transparent so a theme tints it) and `icons.txt` (the names, in order). A test reads the PNG and checks that every named cell is drawn.
3. `HubLayout` gets a `Chrome` (theme button, close, emblem, detail rect and kind, nav style); the four-argument constructor stays for old callers. `HubTheme` gets default draw methods for the new chrome and `focusColor()`, so an old theme needs no change to compile.
4. `HubScreen`: draws and registers the theme button (cycles Grimoire, Blood Moon, Tensura, skipping the ones that cannot be drawn, saved to the config), number keys 1 to 8 jump to a page, Tab follows the zone order, `Frame.detail(Detail)` hands the detail contract to the theme, `Frame.confirm(...)` opens the confirm dialog (Esc cancels, default focus is the safe button).
5. The three existing layouts place a theme button (Tensura gets a 14 px title strip; Grimoire sits above the ribbons; Blood Moon top right). Layout tests at 320 x 240, 480 x 270, 640 x 360, 960 x 540.
6. Matrix, report. Client screenshots only when no other `javaw` runs.
