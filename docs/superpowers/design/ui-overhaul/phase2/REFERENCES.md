# Phase 2 art kit: references

What was looked at before drawing, and what was taken from it. All art in the kit is our own.

| Reference | Taken |
|---|---|
| `../phase1/` (the approved style guide: 22 exports, `palettes.json`, `src/kit-*.js`, `src/icons.js`, `src/scene-*.js`) | Every palette colour, the frame shapes, the button states, the bevel rule (light from the top-left, 1 texel outline), the eight sample icons, the boss bar measures, logo direction B |
| The Figma page "UI Overhaul — Style Guide" (file `USFBf74c4I2BWDyfmRxFZO`, node `83:2`) | The same frames as the exports; not opened again for phase 2 |
| `textures/entity/boss/*.png` (our boss skins) | Hair, skin and eye colours, beards, glasses and collars of the nine human portraits |
| `textures/entity/boss/*_geo.png` (our wolf textures) | Fur and eye colours of the wolf portraits |
| `shared/hub/kit/Icons.java`, `SkillIcons.java`, `data/.../supernatural/skill/*.json`, `ladder/*.json` | The list of icons, skills and bloodlines |
| `parts/hud/client/SlotArt.java`, `core/hud/SlotBadge.java`, `HudLayout` | Slot size (22), icon size (16), key badge places, the 72 dots of the blood ring, the 32 steps of the cooldown pie |
| Scale2x (EPX), a public pixel-art scaling rule | The big letters of the wordmark, as in phase 1 |

The owner's references (Cobblemon, Create and Ponder, Genshin and Hollow Knight menus) set the direction in phase 1. Nothing was copied from them, and no file of theirs was opened for phase 2.

No image-generation model was used. Every sprite comes from `src/*.py`: shapes and bitmaps typed by hand, coloured from named ramps.
